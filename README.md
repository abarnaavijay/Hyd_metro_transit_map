# Hyderabad Metro Transit Tourism Map

## Overview

The **Hyderabad Metro Transit Tourism Map** is an interactive web mapping application designed to help residents and tourists conveniently explore Hyderabad's major tourist attractions using the city's metro network. The project aims to promote sustainable urban tourism by integrating public transportation with location-based tourism information, enabling users to efficiently plan their journeys while discovering the city's rich heritage, historical landmarks, recreational destinations, shopping areas, and other points of interest.

## Project Highlights

* Interactive web map for tourism and metro-based navigation.
* Categorized tourist attractions with informative pop-ups.
* Integration of the Hyderabad Metro Rail network for route awareness.
* OpenStreetMap (OSM) used as the base map for seamless visualization.
* Responsive interface generated using the **QGIS2Web** plugin.
* Hosted using **GitHub Pages** for easy public access.

## Data Sources

* **Metro routes and station information:** Hyderabad Metro Rail Limited (HMRL)
* **Base Map:** OpenStreetMap (OSM)
* **Web Map Development:** QGIS2Web
* **Deployment Platform:** GitHub Pages
* **Google My Maps** for Laying the routes or Metro Corridors

## Technologies Used

* QGIS
